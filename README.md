折れた針で夜を刻め

[Intro]
針の止まった時計が　壁を噛む
一拍ずれて　部屋の輪郭が歪む

[Verse 1]
白紙の地図に　黒い線を引く
出口の矢印　昨日へ向いている
階段の数なら　数えないで行こう
上ったはずなのに　床が遠ざかる

合図は来ない　だから先に踏む
四つ目の足音だけ　違う場所に住む
名前を呼ばれて　振り向いた先に
知らない自分が　同じ口で笑う

[Chorus]
折れた針で　夜を刻め
変わる鍵盤　道を変えろ
足場が消えても　声は残る
崩れる拍の上を　まだ進め

[Verse 2]
青だった窓が　灰色に変わる
息を吐くたび　天井が下がる
正しさの札を　胸から剥がし
裏面に書いた　「まだ終われない」

一歩　二歩　数え方を捨てる
角を曲がれば　景色ごと変える
昨日の約束　ポケットで濡れて
握れば文字まで　指先に消える

[Bridge]
どこから来たかは　もう訊かない
どこへ向かうかも　今は決めない
ずれた鼓動を　この手で拾い
沈む床にも　足跡を残す
